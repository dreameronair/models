# 铁骑狂飙

一款摩托格斗竞速小游戏：一边跑赛道，一边跟身边的对手拳打脚踢，把人打下车。纯静态网页，零依赖，手机和电脑都能直接开。

五条赛道、六人同场、三台可买的车。美术全是 Canvas 当场画的，音效全是 WebAudio 合成的——整个游戏**一张图片、一段音频都没有**，所以单文件版只有 112KB。

## 关于原创

这是一款**原创作品**。玩法类型（摩托竞速 + 骑行中近身格斗）是游戏品类，不受版权保护；但所有具体内容都是自己做的：

- 车手、摩托、汽车、路边景物，全部是 `js/sprites.js` 里用几何图形画出来的原创造型
- 十二个车手的名字、涂装、脾气设定，五条赛道，三台车，都是原创的
- 音效是振荡器合成的，没有采样任何现成音频

没有使用任何第三方的美术、音频或商标。

## 跑起来

```bash
cd moto-brawl
python3 -m http.server 8124
# 浏览器打开 http://localhost:8124
```

或者打包成单文件，双击就能玩、也能直接发给别人：

```bash
npm run build:single      # 产出 dist/moto-brawl.html
```

## 怎么玩

**键盘**：`↑` 加速　`↓` 刹车　`←` `→` 转向　`Z` 左拳　`X` 右拳　`C` `V` 左右飞踢　`Esc` 暂停

**手机**：自动给油，左下角转向，右下角刹车和拳脚。

要点：

- 只有跟对手**并排**时出手才打得中，空挥一样要等冷却
- 血被打空就会摔车，爬起来要好几秒，名次基本就没了
- 路边偶尔有**钢管**，捡到后几下攻击伤害翻倍
- 正面撞上社会车辆直接摔车，擦身而过只掉速掉血
- 跑进前三才解锁下一条赛道；名次换奖金，攒钱去车库换车

## 伪 3D 是怎么画的

赛道被切成一段段等长的路面。每段记着自己的世界坐标、弯曲度和挂在上面的景物。渲染时把每段的两个端点投影到屏幕，画成一个梯形。

关键在顺序：**路面从远往近画**，一边画一边记住当前画到的最高屏幕 y，比它还低的段直接跳过。这样翻过坡顶时，坡后面的路会被坡自然挡住，不需要任何深度缓冲。**精灵反过来从远往近盖**，并用所在路段记下的 `clip` 裁掉陷进山坡里的部分。

精灵的缩放基准是**投影之后的路面半宽**（`spot.w`），而不是原始的投影比例——后者没把路宽算进去。

## 难度是配出来的，不是拍脑袋

数值不要凭手感改，改完跑一遍：

```bash
npm run balance             # 五条赛道各跑 20 局，看名次、摔车、用时
npm run balance --runs 40 --skill 0.6    # 换个更手生的玩家再看
```

机器玩家会走内线、躲车、也会揍人，跟游戏里的 AI 共用同一套逻辑（`tools/sim.js`），所以测出来的数跟真实手感是对得上的。

配平时抓到过三个让比赛根本没法玩的问题，都记在这里以免重蹈覆辙：

**离心力压不住方向。** 转向每帧给 `dx`，离心力给 `dx * pct * curve * centrifugal`，两者之比就是 `pct * curve * centrifugal`。原来 `centrifugal` 是 0.32，配上 `curviness` 1.35 的林道，最急的弯比值到 2.6——方向打满也必被甩出赛道，那不是难度，是无解。现在 `centrifugal` 降到 0.15 并给单段弯道加了 6.5 的上限，满速过最急的弯比值是 0.975，打满刚好压得住，松点油门就轻松。`curviness` 的作用也从「急弯更离谱」变成了「急弯更密」。这条比值有测试盯着。

**交通车一碰就摔，而且车距太小。** 极速下一秒要跑一万多个世界单位，原来最密的城区平均车距才 2900，等于必撞。现在车距拉到 6000 起，并且只有正面撞上才摔车，擦边只掉速掉血。机器玩家的平均摔车次数从 13.9 降到 1.4。

**五个对手轮流围殴。** 单看一个对手的出手频率还算克制，乘以五就是玩家全程在地上爬。频率降到三分之一，并且加了一次出手之后的间隔，给玩家反打和拉开距离的机会。

赛道的 `rivalSkill` 是「这条赛道的整体节奏」，直接乘在对手极速上，数值是照着**预期骑哪台车**反推的：前两条用起步车，中间两条换重机车，最后一条上刀锋。所以攒钱换车是真的有用，而不是摆设。

## 测试

```bash
npm test                # 逻辑，73 项，纯 Node 无需浏览器
npm run test:browser    # 端到端，42 项，需先 npm i && npx playwright install chromium
```

`test_race.js` 覆盖随机数可复现、赛道首尾相接、弯道上限、投影的远近关系、油门刹车与离地掉速、格斗的距离与朝向判定、冷却、钢管、摔车与爬起、交通车擦碰与正撞的区别、名次排序、读秒，以及五条赛道跑完不出现 NaN。还有一节直接跑模拟对局，断言难度曲线没有塌陷、经济链攒得动换车。

`test_browser.js` 真实驱动页面：菜单跳转、赛道解锁、键盘驾驶、出拳踢腿、暂停、结算与奖金、买车、刷新后存档还在，以及手机视口下自动给油和触屏按钮。最后一节会现打一份单文件版，**复制到临时空目录**再用 `file://` 打开——留在 `dist/` 下测的话隔壁就是 `js/` 和 `css/`，漏网的相对路径照样能加载，等于没测。
