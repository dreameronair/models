# 我们的太阳系 · 儿童科普动画

一条约 2 分 40 秒的 1080p 儿童科普动画：坐小火箭从太阳出发，按顺序拜访八大行星，最后把行星排在一起比大小、背口诀“水金地火木土天海”。全中文配音 + 字幕 + 音乐盒背景音乐和音效。

画面、音乐、音效全部由代码生成，没有使用任何外部图片或素材库；配音用微软 Edge 在线语音（晓晓）。

## 内容

| 段落 | 讲什么 |
| --- | --- |
| 开场 | 标题、小火箭出发 |
| 太阳 | 会发光发热的恒星，能装下 130 万个地球（旁边放一个小地球对比） |
| 行星家族 | 俯视轨道图，八颗行星依次出现并标名字 |
| 水星 → 海王星 | 每站一颗行星：站点徽章、名字、知识卡片，外加专属小演示（水星速度线、金星温度计、月亮绕地球、火星火山对比、木星大红斑和地球比大小、土星冰块光环、天王星躺着转、海王星大风） |
| 比大小 | 按真实半径比例排列，“木星最大、水星最小”，口诀逐字弹出 |
| 结尾 | 太阳系真奇妙，下次见 |

## 怎么做出来的

```
script.json ──tts.py──▶ 每句配音 + timeline.json（时间轴由真实配音长度决定）
                              │
scene/solar.js  seek(t) ◀─────┘   画面 = 时间轴和 t 的纯函数
     │
render.js  无头 Chromium 逐帧截图 ─▶ ffmpeg 分段编码 ─▶ build/video.mp4
     │                                 （多进程并行，每段独立）
     └─▶ cues.json（音效时间点，和画面同源）
                              │
audio.py  音乐盒配乐 + 音效 + 人声闪避混音 ─▶ build/mix.wav
                              │
mux.sh   响度标准化 (-16 LUFS) + 合成 ─▶ out/solar_system_kids.mp4
```

- **改文案就重新生成**：时间轴是从配音长度算出来的，改 `script.json` 里的台词后重跑，画面节奏会自动跟上。
- **确定性**：场景代码里禁止 `Date.now`、`Math.random`、帧回调等；`npm run check` 会验证同一时间点反复渲染像素完全一致、相邻帧确实在动。
- **卡通行星**：每颗行星都是 Canvas 程序化绘制的球体（经纬投影的陨石坑/大陆/云带、明暗、光环前后遮挡），带会眨眼的表情。

## 运行

需要 Node 18+、Python 3（numpy、edge-tts）、ffmpeg。

```bash
npm install && npx playwright install chromium
pip install numpy edge-tts
npm run build          # 配音 → 检查 → 渲染 → 配乐 → 合成，产物在 out/
```

单步：

```bash
npm run voice                                 # 只生成配音和时间轴
node tools/render.js --stills 20,52,99        # 导出几张静帧看效果
npm run preview  # 打开 http://localhost:8080/scene/index.html?preview 拖动进度条预览（带声音需先跑 audio）
```

## 科学内容核对

- 太阳体积约为地球 130 万倍；木星约 1300 多倍。
- 水星公转周期 88 天；金星表面约 460°C，是最热的行星，也是夜空中最亮的行星。
- 火星奥林匹斯山约 22 km，珠峰约 8.8 km，约 2.5 倍。
- 大红斑直径大于地球；土星环主要由冰块和岩石组成；天王星自转轴倾斜约 98°。
- 海王星风速可达约 2000 km/h，约为大型客机巡航速度（约 900 km/h）的两倍多。
